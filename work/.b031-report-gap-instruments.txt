CROSS-FILE GAPS

- src/rules/derive.ts:3409 `ownedFeatureIds(c, db)` never consults `c.classArchetype.suppressedFeatures`.
  It rebuilds the owned set from `cls.features` alone, so a class archetype's REMOVED features still
  read as owned. buildCharacter's own local set does honour it (build.ts:5885-5890,
  `for (const id of archSuppressed) ownedFeatureIds.delete(id)`) — the two functions give different
  answers to the same question, and the exported one is what the sheet snapshot diffs
  (scripts/lib/sheet-snapshot.mjs:50) and what modeGateIds reads.
  MEASURED: a level-20 wizard with War Mage Dedication and NO Spellshield already has
  ownedFeatureIds ∋ 'arcane-bond', although our own record says of the archetype "you never gain
  Arcane Bond, Arcane Thesis, or Defensive Robes" (feats/war-mage-dedication.classArchetype.note,
  suppressFeatures ['arcane-bond','arcane-thesis','defensive-robes']). Because the wizard already
  "owns" it, Spellshield's printed "You gain the Arcane Bond class feature and the Drain Bonded Item
  action" (AoN feat-7983) adds nothing observable and the record scores 0 on its correct host — where
  on the fighter it scored 5 by giving a fighter a wizard feature nobody had suppressed.
  So spellshield's OK was luck, and its new 0 is a TRUE POSITIVE: the harness is now reporting a real
  engine defect instead of hiding it behind the wrong host. The fix (one line, `for (const id of
  c.classArchetype?.suppressedFeatures ?? []) out.delete(id)` at the end of ownedFeatureIds) is in
  src/rules/derive.ts, outside this agent's assigned file, so it is reported and not edited.
  It is the same defect from the other side as the data-rows family's open line
  "src/sheet/FeatsTab.tsx … prints War Mage's suppressed 'arcane-bond' under Replaced on the same
  character whose Spellshield grants it (spellshield#arcane-bond-listing)" — one fix in derive.ts
  plus that family's re-grant exclusion settles both. Whoever takes it should re-play spellshield
  through the harness in the same change; it is the only record in the measured 22 that needs it.
