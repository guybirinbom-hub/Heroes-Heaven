# Gold set — for review

43 feats. For each: its printed text, and what three independent readers said a character sheet
must be able to express. **Your corrections make this the answer key** that every later model run
is scored against — so a wrong entry here propagates into all 6,206 feats.

**Referencing.** Feats are numbered 1–43; each requirement carries a number like `14.2`. Say
"14.2 is wrong, it should be a status bonus" or "delete 27.3" and I can apply it exactly.

**How to read a row.** `3/3` means all three readers independently named that requirement —
strong. `1/3` means only one did, and those are where your eye is most worth spending. The Foundry
column is a second opinion from an unrelated implementation; it is corroboration, never a source.

**The six `inert` feats are controls.** Every clause in them lands on an ally or an enemy, so per
your Ruling F the correct answer is *no requirements at all*. If a reader produced any, that is
over-flagging, and it is called out below.

**Summary:** 43 feats · 176 proposed requirements · 6 feats where all readers agreed nothing is required · 1 control(s) violated.
